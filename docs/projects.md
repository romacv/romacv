## Shortcuts

`repos/<name>` is a relative link to `../../<name>`, so it opens the checkout when this repo sits in `~/Dev/romacv` and dangles anywhere else. `repos/**` and `docs/**` are excluded from Firebase Hosting in `firebase.json`.
