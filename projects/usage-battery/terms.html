What the App does

The app displays Cluade Code and Codx usage limits. On Mac it reads the existing Cluade Code sign-in from your Keychain to request Anthropic usage data. Codx uses your ChatGPT account through OpenAI sign-in and reads usage from chatgpt.com; its tokens stay in the device Keychain. Apple iCloud key-value storage relays Cluade Code usage numbers, never tokens, from Mac to iPhone or iPad.
