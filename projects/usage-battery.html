Track Clode Code Usage From Your Mac Menu Bar

Usage Battery shows your Clode Code session, weekly and Sonnet-model usage as a color-coded battery icon that updates automatically — with an iOS companion app coming soon. It's listed on the App Store as "Usage Battery for Clode Code".

Download on the App Store

What it does

Usage Battery is a native macOS menu bar app built for developers who use the Clode Code CLI and want to see how much of their usage limit is left without switching to a terminal. It tracks three periods — the current 5-hour session, the 7-day weekly limit, and Sonnet-model usage when available — and turns each into a battery-style progress bar that goes from green to orange to red as you approach the limit, along with a reset timer. A companion iOS app is in development and is not yet available on the App Store.

How it works

The app reads the OAuth token that the claude CLI already stores in your macOS Keychain after you run claude in Terminal once, then calls Anthropic's own usage API directly with that token. Nothing runs through a third-party server: there is no backend, no analytics SDK, and no data collection by the developer. The upcoming iOS companion is designed to receive the same credentials via iCloud Keychain sync from the Mac app.

Who it's for

Anyone who works with Clode Code regularly and wants an always-visible, at-a-glance sense of remaining quota instead of checking usage manually.

Key features

  • Menu bar battery icon for session, weekly and Sonnet usage
  • Color-coded progress bars with reset timers
  • Auto-refresh, no manual token entry after first setup
  • iOS companion app coming soon
  • Local-only: reads your own Keychain token and calls Anthropic's API directly
