# Секреты

`setup.sh secret` собирает JSON для Secret Manager `AUTOPOST` из приватных файлов по [шаблону](../setup/keys-template.md). Значения не хранить в репозитории, логах, истории команд или чате. Этот каталог не служит хранилищем ключей.

После обновления выполнить redeploy webhook, worker и daily и проверить привязки. Затем вручную уничтожить прежнюю неиспользуемую версию в Console: AUTOPOST → Versions → Actions → Destroy. Автоматической очистки нет; версии действующих deployments сохранять.

Держать приватную резервную копию. Настройка: [инструкция](../docs/autopost.md).
